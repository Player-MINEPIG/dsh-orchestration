# Example host delegation policy

The task-management plugins own durable task identity, scope, history and results. The host agent may delegate a specifically authorized activity, such as computer use, to an installed local specialist through an existing skill.

Pass the objective, verified environment/workspace, current authorization, constraints, acceptance criteria and task/run identity. Do not copy the full conversation or credentials. If the specialist cannot operate within those permissions, return the exact blocker. Keep substantive updates and artifacts under the same task. Do not infer success from a tool call or final chat text; submit the explicit result through the task contract.

This file is an optional configuration example. It does not install Codex, grant persistent access, generate credentials, enable a new computer connection or add plugin self-maintenance.
