协议与权威

来源完整 JSON 快照→ durable outbox→ HTTPS / SSH 隧道→ 校验 + 原账本事务 + receipt→ 中央监看 / 复核

dsh.project-registration/v1 接受来源 namespace、projectExternalId、连续整数 revision、previousRevision、idempotencyKey 与 observedAt。内部身份为 SHA-256(namespace, project, entity kind, external identity)，与中央执行身份隔离。身份映射随 receipt 返回，重放跨重启保留。严格 JSON 拒绝未知字段、悬空引用、循环关系和 parent run/task 不一致；单包 1.9MB。

归属字段与动作
来源项目事实、工作区 URI、任务事实和组织关系、Run 状态/执行引用、不可变 Report 与 Artifact 引用、Outcome 标题/摘要/关系、原始时间、来源验收声明。
中央registration note/review/review evidence/revoked（带独立 expectedRevision 与可信 actor）；Outcome feedback/state（必须保持来源事实与关系）。来源下一 revision 保留所有允许的中央字段。
来源撤回withdrawProjectRegistration 需来源 namespace 授权与预期 revision，只停止该登记继续摄入，保留证据。不取消本地执行。中央停收可显式解除。
执行授权所有导入 task.kind=observed、Run.observationOnly=true。createRun、claim、continue、schedule、cancel/reconcile 的已有准入约束保留；不创建 route、Attempt、调度或生产作业。希望再做工作需另行建立已授权中央任务。

live 可从未结束项目开头登记并持续提交完整更新；final 可一次性首次提交或从 live 收尾，封存后拒绝新 revision；history 可录入已结束或未结束的历史快照，同样封存。history 不可覆盖同身份的 live。更正既有证据需追加新身份；封存后后续工作或补充证据使用明确的新来源项目身份，不默默改写旧 receipt。完整更新不能删掉已有实体；报告/产物不可改写，终态 Run 不可改写。

未知原始时间使用 JSON null。账本模型必需时间仅用导入技术占位；来源包保留 null，面板明确显示未知。observedAt 是本次抽取/观察时间，importedAt/recordedAt 是中央接收时间；都不冒充原执行的开始/结束。

路径入口
