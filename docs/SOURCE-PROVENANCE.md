# Source provenance

The repository retains the three commits supplied in the original
`repository.bundle`, whose `main` and `HEAD` point to
`86d8fb014d97fbfe282fcea54d4d8a899a24bb97`.

The subsequent complete source archive identifies its upstream source as
`ac193aeb76ffd663d303055a033ee3143a7ee81e`. Its Git objects and intervening
history were not supplied. The available bundle does not contain that commit,
and no additional bundle was found in the delivery directory. The full source
snapshot, including the live WebUI, is therefore restored in a new commit on
top of the supplied history. It is not represented as the original `ac193ae`
commit.

Runtime databases, environment files, dependency/build directories and the
deployment handoff inventory are excluded. Synthetic test fixtures remain.
The original deliveries and bundle are preserved separately.
